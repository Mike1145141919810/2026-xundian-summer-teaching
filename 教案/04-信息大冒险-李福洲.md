# 教案：《信息大冒险》

> **课程系列**：数字魔法师 · 第4讲
> **授课教师**：李福洲（计算机学院）
> **授课时间**：7月30日 11:10-12:00（50分钟）
> **授课对象**：寻甸县雷锋希望小学学生（3-6年级混龄）
> **课程类型**：信息与编码启蒙 · 角色扮演游戏课

---

## 一、教学目标

| 维度 | 目标 |
|------|------|
| **认知** | 理解信息在网络中不是"一整段"传过去的，而是分成小包转发的；理解丢包和重传的基本概念 |
| **技能** | 能描述一次完整的信息传输过程（发送→分包→路由→组装）；能解释为什么需要"编号"和"确认" |
| **情感** | 体验"协作完成任务"的乐趣；对"发一条微信背后发生了什么"产生好奇 |

---

## 二、教学重难点

- **重点**：信息分包传输、路由转发的过程
- **难点**：理解为什么需要"编号"——数据包可能乱序到达，需要编号来重新排列

---

## 三、教学准备

| 物品 | 数量 | 说明 |
|------|------|------|
| 大信封（或纸袋） | 4-6个 | 模拟"数据包"，贴上编号标签 |
| 小纸条（消息内容） | 若干 | 写有不同的消息，剪成小段 |
| 角色标识牌 | 4种各若干 | "发送者""路由器1""路由器2""接收者" |
| 胶带/绳子 | 2条 | 在地上贴出/拉出"网络路线" |
| 计时器（手机即可） | 1个 | 记录传输时间 |

> 所有道具零经费：信封用纸折，标识牌用纸片写，路线用粉笔画或胶带贴。

---

## 四、教学过程

### 环节一：情景导入——"你的微信是怎么发出去的？"（5分钟）

**教师活动**：
1. 提问："你给朋友发一条微信，点击发送，对面马上就收到了。这中间发生了什么？"
2. 学生自由猜测（"从天上飞的""走网线""WiFi信号"等）。
3. 揭题："信息不是一整条飞过去的，而是被切成一小块一小块，像快递一样一站一站转过去的。今天我们来当快递员——把一条消息从教室这头传到那头！"
4. 板书课题：**《信息大冒险》**

---

### 环节二：角色扮演第一轮——"直接传递"（10分钟）

#### 布景准备（2分钟）

1. 在地上画出路线：
   ```
   发送者 ──── 路由器1 ──── 路由器2 ──── 接收者
   ```
2. 分配角色：1个发送者、2个路由器、1个接收者，其余同学当"观察员"。

#### 规则说明（2分钟）

1. 发送者拿到一条完整消息（写在小纸条上），直接走过去递给路由器1。
2. 路由器1再递给路由器2。
3. 路由器2递给接收者。
4. 接收者念出消息内容。

#### 第一轮游戏（6分钟）

1. 选一组学生上场，传递一条消息（如"下午三点操场集合"）。
2. 观察员记录：用了多久？有没有出错？
3. 讨论问题：**"如果路由器1'死机'了（退出游戏），消息怎么办？"**
   - 学生可能会说"换一条路"——引出"网络有备用路径"的概念。

---

### 环节三：角色扮演第二轮——"分包传输"（15分钟）

#### 引入问题（3分钟）

1. 教师写一条很长的消息在黑板上（40个字左右）。
2. 提问："如果一条消息很长，一个'快递员'拿着纸条走，万一丢了怎么办？全都没了！"
3. 引出方案："把大消息切成小块，每块加上编号，分开送。丢了也只丢一小块，重发那一块就行。"

#### 分包演示（5分钟）

1. 把长消息剪成4段，分别装进4个信封，信封上标编号：1/4、2/4、3/4、4/4。
2. 发送者把4个信封分别交给4个不同的"数据包快递员"（新增角色）。
3. 4个快递员同时出发，可以走不同路径（如果有多个路由器）。
4. 接收者按编号重新排列，还原完整消息。

#### 制造故障（7分钟）

1. **场景一：丢包**——教师偷偷拿走其中一个信封（比如3/4）。
   - 接收者发现少了3号包，怎么办？
   - 引导："接收者可以喊'3号包没到，请重发！'"
   - 发送者重新发送3号包。

2. **场景二：乱序到达**——4个快递员故意以不同顺序到达。
   - 接收者手中收到：1/4、4/4、2/4、3/4（乱序）。
   - 引导学生发现："有编号就可以重新排好！1→2→3→4。"

3. **场景三：重复到达**——同一个包被送了两次。
   - 接收者发现两个3/4号包，怎么办？→ "扔掉重复的！"

**设计意图**：通过"制造事故"的方式让学生理解网络协议的三大核心机制——丢包重传、编号排序、重复去重。

---

### 环节四：全班大游戏——"网络大冒险"（15分钟）

#### 游戏规则（3分钟）

1. 全班分成4个组，分别扮演：
   - **发送组**：负责拆分消息+编号+发出
   - **路由组**（2个组）：负责转发，但可以制造"故障"
   - **接收组**：负责接收+排序+还原+检查
2. 教室布置成网络拓扑：

```
   发送组 ──→ 路由组A ──→ 路由组B ──→ 接收组
                ↘          ↗
                  路由组C
```

3. 规则：
   - 发送组把消息分成最少5个包，编号后发出。
   - 路由组可以随机"丢包"（扣下不传），但不能丢超过2个。
   - 路由组可以"延迟"某些包（最后再传）。
   - 接收组还原消息后，检查是否完整，不完整就喊"重传编号X！"

#### 游戏进行（10分钟）

1. 第一轮：用一条20字的简单消息。
2. 教师计时，记录各环节用时。
3. 第二轮：换一组消息，难度升级——路由组增加干扰（故意传错编号、多传一个别人的包等）。

#### 游戏后讨论（2分钟）

- "接收组是怎么知道消息'完整'了？"→ "看编号，连号就是完整。"
- "如果你的微信消息在路上丢了，你的手机会怎么做？"→ "自动重发，你根本不知道。"

---

### 环节五：总结（5分钟）

1. 回顾三个核心概念（板书）：

```
信息传输三要素：
① 分包 —— 把大消息切成小块
② 编号 —— 每块标上"第几块/共几块"
③ 重传 —— 丢了就喊"再来一次！"
```

2. 联系生活："你每发一条微信，背后就有无数个'快递员'在帮你传这些小包——这就是互联网的运作方式。"
3. 预告下节课："明天就是我们的最后一节课——《画里的数字》，我们来看看一张照片是怎么变成数字的！"

## 五、板书设计

```
《信息大冒险》——网络是怎么传信息的

  发送者 ──→ 路由器1 ──→ 路由器2 ──→ 接收者

  📦 分包：大消息 → 切成小块
  🔢 编号：每块标号 1/4, 2/4, 3/4, 4/4
  🔄 重传：丢了就喊"X号包请重发！"

  核心三要素：分包 | 编号 | 重传

  你的微信、视频、游戏，都是这么传的！ ✨
```

## 六、教学建议与注意事项

1. **空间需求**：需要教室前面留出足够的走动空间。如果教室太小，可以改为"传纸条"形式，学生坐着传递，通过多列传递来模拟路由。
2. **角色轮换**：确保让尽量多的学生都有机会当一次"发送者"或"路由器"，而不是全程旁观。可以轮换角色多玩几轮。
3. **混龄应对**：低年级多参与简单的"传纸条"角色；高年级可以担任"接收组"负责还原和检查。
4. **故障设计**：丢包、乱序、重复等"故障"是本节课最出彩的地方，教师要在游戏中自然制造——不要提前预告，让学生在体验中自己发现问题和解决方案。
5. **课堂纪律**：走动环节容易混乱，需要提前讲清楚"不可跑、不可推挤"的安全规则。教师喊"开始"和"停"作为信号。
6. **趣味加分**：可以给每个角色配一个小道具——发送者拿"手机"（纸板做的），路由器拿"文件夹"，接收者拿"放大镜"，增强代入感。
