> **课程系列**：数字魔法师 · 第3讲

> **授课对象**：寻甸县雷锋希望小学学生（3-6年级混龄）
> **课程类型**：信息与编码启蒙 · 互动游戏课

---

## 一、教学目标

| 维度 | 目标 |
|------|------|
| **认知** | 理解数据压缩的基本思想：去掉冗余、用更少的符号表达同样的信息 |
| **技能** | 能对重复字符序列使用游程编码进行压缩；能判断一段信息"压缩后是变大还是变小" |
| **情感** | 感受"用聪明方法节省空间"的乐趣；理解"压缩"在日常生活中的普遍性 |

---

## 二、教学重难点

- **重点**：游程编码（RLE）的基本操作——数连续重复字符的个数
- **难点**：理解"不是所有东西都能压缩"——没有规律的随机数据反而更"大"

## 四、教学过程

### 环节一：情景导入——"大象怎么塞进冰箱？"（5分钟）

**教师活动**：
1. 先不讲压缩，拿起一件羽绒服，问学生："这件衣服体积很大，怎么让它变小？"
   - 学生自然会说："塞进袋子！用力压！"
2. 现场演示：把羽绒服塞进塑料袋，挤出空气。
3. 提问："变小的衣服和原来有什么不同？还能穿吗？"
   - 引导：衣服还是那件衣服，只是去掉了"空气"。
4. 揭题："计算机里存东西也一样——有些文件里面很多'空气'，我们可以去掉它们让文件变小。今天我们就来学怎么把'大象塞进冰箱'！"
5. 板书课题：**《把大象塞进冰箱》**

**设计意图**：用生活化的物理形象建立"压缩"的直觉。

---

### 环节二：游程编码——"AAAAA = 5个A"（20分钟）

#### Step 1：发现冗余（5分钟）

1. 在黑板上写两行"加密消息"：

```
第一行：A A A A A A A A A A A A A A A A A A A A
第二行：W E R T Y U I O P A S D F G H J K L Z X
```

2. 提问：
   - "第一行有什么特点？"→ 全是同一个字母A！
   - "如果让你传纸条，第一行你会怎么写？"→ "20个A"
   - "同样的思路，'BBBBBBBBBB'你怎么写？"→ "10个B"

3. 引出核心思想：**"用'几个什么'来代替'一个一个列出来'，这就是压缩！"**

#### Step 2：动手压缩（10分钟）

1. 给出第一条消息：

```
原始：B B B B B B B W W W W W W W A A A
```

2. 教学生用游程编码规则：
   - 写"7B" 代替"BBBBBBB"
   - 写"7W" 代替"WWWWWWW"
   - 写"3A" 代替"AAA"
   - 压缩结果：**7B 7W 3A**

3. 对比：原来需要17个字符，现在只需要7个字符（含空格）！

4. 让学生自己练习：

```
练习题1：G G G G G → 5G
练习题2：Z Z Z Z Z Z Z Z Z Z → 10Z
练习题3：X X X X X Y Y Y Y Y Z Z Z Z Z → 5X 5Y 5Z
练习题4：A A A B B B B B C C C C C C C → 3A 5B 7C
```

#### Step 3：进阶挑战——黑白图像（5分钟）

1. 在黑板上画一个8×8的简单黑白格子图（比如一个黑色方块），用0表示白、1表示黑。
2. 逐行写出原始编码（64个0和1），让学生感受"好多！"。
3. 用游程编码压缩——"23个0、2个1、22个0……"。
4. 对比："原来要写64个数字，现在只要写几个'几个什么'！这就是图片压缩的原理！"

**设计意图**：从一维字母到二维图像，让学生感知压缩的普遍性和威力。

---

### 环节三：压缩的"边界"——不是什么东西都能变小（10分钟）

#### Step 1：反例演示（5分钟）

1. 给出一条"随机"消息：

```
W E R T Y U I O P
```

2. 让学生尝试用游程编码压缩——发现每个字母都不连续重复，写出来变成"1W 1E 1R 1T 1Y 1U 1I 1O 1P"，反而更长了！
3. 结论：**"压缩只能去掉重复的东西，没有重复就没办法压缩。就像你没法把一块石头再变小——它里面没有空气。"**

#### Step 2：生活例子（5分钟）

1. 提问互动：
   - "什么样的衣服容易压缩？" → 羽绒服（很多空气）
   - "什么样的不容易？" → 石头（实的）
   - "照片为什么能压缩成更小的文件？" → 大片同色区域
   - "考试卷子扫描成PDF为什么能变小？" → 很多空白区域

2. 总结：**压缩 = 找规律 + 去掉重复**

---

### 环节四：压缩接力赛（10分钟）

**游戏规则**：
1. 全班分成4组，每组拿到一条"原始消息"（见附录）。
2. 比赛：哪组能压缩到最短。
3. 每组选代表把压缩结果写在黑板上。
4. 评选"最佳压缩大师"——压缩率最高的小组获胜。

**注意**：压缩结果必须能还原！不能丢信息。（引入"无损压缩"概念——压缩了还能一模一样变回来。）

---

### 环节五：总结（5分钟）

1. 回顾三个收获：
   - "压缩就是去掉重复、用更少的字符表达同样的信息。"
   - "'几个什么'（游程编码）是最简单的压缩方法。"
   - "没有规律的东西不好压缩——压缩需要找到重复。"
2. 联系生活："你手机里的照片、视频、音乐，全都是压缩过的！不然手机根本存不下。"
3. 预告下节课："学会了压缩，下节课我们来玩一个更有趣的游戏——模拟信息在网络上怎么传输，有'丢包'和'黑客'哦！"

## 五、板书设计

```
《把大象塞进冰箱》——数据压缩

  羽绒服 🧥 → 挤出空气 → 变小了！（还是那件衣服）

  文字压缩：
  AAAAAAAAAAAAAAAAAAAA  →  "20个A"
  BBBBBBBWWWWWWWAAA      →  7B 7W 3A

  规则："几个 + 什么" = 游程编码（RLE）

  "WERTYUOP" → 1W 1E 1R… 反而更长了！
```

## 七、教学建议与注意事项

1. **游程编码名称**：不必强制学生记"游程编码"或"RLE"这个词，他们只要能理解"几个什么"就够了。名词提一下即可。
2. **压缩率计算**：如果有高年级学生，可以引入压缩率概念——压缩后大小÷原始大小。低年级跳过。
3. **羽绒服演示**：如果现场没有羽绒服，用塑料袋+棉花/废纸团也可以，核心是展示"除去空隙"的直观感受。
4. **道具备选**：没有实物的话，用手比划"大"→ 挤压 → "小"也行，配合夸张表情。
5. **趣味加分**：如果有时间，可以让学生自己想一句"最难压缩"的话（每个字都不一样），互相挑战。
