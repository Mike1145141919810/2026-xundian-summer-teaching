# 教案：《0和1的世界》

> **课程系列**：数字魔法师 · 第1讲
> **授课教师**：梁海欣（计算机学院）
> **授课时间**：7月29日 9:00-9:50（50分钟）
> **授课对象**：寻甸县雷锋希望小学学生（3-6年级混龄）
> **课程类型**：信息与编码启蒙 · 互动游戏课

---

## 一、教学目标

| 维度 | 目标 |
|------|------|
| **认知** | 知道计算机内部只用0和1表示所有信息；理解"二进制"就是逢二进一的计数方式 |
| **技能** | 能用5张二进制卡片表示0-31的任意数字；能将简单十进制数转换为5位二进制 |
| **情感** | 产生"计算机原来是这样想的"的好奇心；消除对计算机的陌生感和神秘感 |

---

## 二、教学重难点

- **重点**：二进制逢二进一的基本规则，卡片计数法
- **难点**：理解"计算机里文字、图片、声音最终都是0和1"

---

## 三、教学准备

| 物品 | 数量 | 说明 |
|------|------|------|
| 二进制卡片（大号演示用） | 5张 | A4纸对折，分别写上16、8、4、2、1，正面加点（●），反面空白 |
| 二进制卡片（学生用） | 每人5张 | 小号，手掌大小即可，同样标16/8/4/2/1 |
| 黑板/大白纸 | 1块 | 用于板书和演示 |
| 粉笔/马克笔 | 若干 | |

> 卡片制作：用普通A4纸打印或手写即可，零经费。卡片的"点"用笔画圆点。

---

## 四、教学过程

### 环节一：故事导入——"计算机的语言"（5分钟）

**教师活动**：
1. 提问："同学们，你们觉得计算机聪明吗？它为什么会算数、会放视频？"
2. 让学生自由发言。
3. 揭题："今天我们来学计算机'说话'的方式。计算机只会说两个字：0 和 1。"
4. 板书课题：**《0和1的世界》**

**设计意图**：制造认知冲突——"只会两个数字怎么表达一切？"激发探究欲望。

---

### 环节二：卡片游戏——用5张卡片数到31（15分钟）

#### Step 1：教师演示（5分钟）

1. 拿出5张大卡片（16、8、4、2、1），排列在黑板/桌面上，有圆点的一面朝上。
2. 解释规则：**"有圆点=1，翻过去没有=0，把所有圆点朝上的卡片数字加起来，就是我们要表示的数字。"**
3. 逐个数数演示：

| 数字 | 卡片状态（16/8/4/2/1） | 二进制 |
|------|------------------------|--------|
| 1 | ●●●●●→翻面→●●●●● 只留1 | 00001 |
| 2 | 只留2 | 00010 |
| 3 | 留2+1 → 2+1=3 | 00011 |
| 4 | 只留4 | 00100 |
| 5 | 留4+1 → 4+1=5 | 00101 |
| … | … | … |
| 31 | 全部朝上 → 16+8+4+2+1=31 | 11111 |

4. 引导学生发现规律：**"5张卡片最多能表示0到31，一共32个数！"**

#### Step 2：学生动手（8分钟）

1. 每人发5张卡片。
2. 教师喊数字："3！""7！""15！""31！""0！"，学生翻卡片表示。
3. 同桌互相出题、翻卡片。

#### Step 3：挑战赛（2分钟）

- 教师快速喊数字，看谁翻得最快最准。
- 难度升级："24！""10！""18！"

**设计意图**：通过身体参与（翻卡片）建立直观的二进制映射，不需要任何数学基础。

---

### 环节三：身体摆数字——"我们都是二进制"（12分钟）

1. 请5位同学到讲台前站成一排，从左到右分别代表16、8、4、2、1。
2. 规则：**"站着=1，蹲下=0"**。
3. 教师喊一个数字，5位同学用站/蹲姿势摆出来。
   - 例如喊"5"：第4位（4）站、第5位（1）站，其他蹲。
   - 台下同学来"解码"：看看，是几？
4. 换几组学生上台，轮流扮演不同"位"。
5. 全班一起做：坐在座位上，每个学生只负责1位（比如只负责"2"这一位），教师喊数字，负责对应位的学生起立。

**设计意图**：用全身动作加深记忆，同时让全班都能参与。混龄情况下，低年级也可以参与——只要记住"站或蹲"。

---

### 环节四：拓展——"所有东西都是0和1？"（10分钟）

**教师活动**：
1. 回到开头的悬念："计算机只会0和1，那文字怎么表示？"
2. 展示一张简单的编码表（贴在黑板上）：

| 字母 | 二进制编号 |
|------|-----------|
| A | 00001 |
| B | 00010 |
| C | 00011 |
| … | … |
| Z | 11010 |

3. 演示：把"HI"翻译成二进制——H=01000, I=01001 → "01000 01001"
4. 让学生尝试用自己的名字首字母编码。
5. 简单引导："图片也是一样，我们31号那节课《画里的数字》就会学到！"

**设计意图**：为后续课程埋下伏笔，让学生对整个系列有期待。

---

### 环节五：总结（3分钟）

1. 回顾三个收获：
   - "计算机只认识0和1，这叫二进制。"
   - "5个二进制位能表示32个不同数字。"
   - "所有文字、图片、声音，最终都是0和1。"
2. 预告下节课："学会了0和1，下节课我们来用它们传递秘密消息——密码课！"

```

   16    8    4    2    1
  [●]  [●]  [●]  [●]  [●]    ← 卡片（圆点面）

   站着=1  蹲下=0

   二进制 → 十进制：把所有"1"位的数字加起来！

   5张卡片 → 0~31，共32个数字 ✨
```

## 六、教学建议与注意事项

1. **混龄应对**：低年级学生如果不会加16+8+4+2+1，没关系——翻卡片游戏不需要计算，只要会"一眼看出来"。高年级可以挑战"十进制转二进制"。
2. **节奏控制**：卡片游戏是核心，要保证每人都有充足的动手时间。如果时间不够，环节四可以压缩。
3. **卡片替代方案**：实在来不及做卡片的话，用纸片写数字+折角标记正反面也行。
4. **课前自测**：教师自己先熟练5位二进制，能脱口而出0-31对应的二进制表示。
5. **趣味加分**：如果学生基础好，可以引入"手指二进制"——用5根手指的伸屈表示0-31，回家可以跟家长显摆。
