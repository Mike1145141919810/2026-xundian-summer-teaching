# "数字魔法师"——2026暑期寻甸信息技术支教

> **华东师范大学 · 计算机科学与技术学院**
> **2026年暑期社会实践 · 寻甸县雷锋希望小学**
>
> 依托计算机学院学科特色，面向寻甸乡村小学开展"数字魔法师"系列信息科学启蒙课程。

## 项目简介

本项目是华东师范大学 2026 年第二阶段主题社会实践 **J-3 "定点帮扶，助力振兴"寻甸县专项** 的一部分。

教学团队在寻甸县雷锋希望小学面向 3-6 年级学生开展 5 讲信息科学启蒙课程，以零机房依赖的互动游戏和动手实践形式，带领孩子们走进计算机科学的奇妙世界。同期开展学校信息化教育现状微调研，形成"教学 + 调研"双线成果。

- **支教学校**：寻甸县雷锋希望小学（3-6 年级）
- **时间**：2026 年暑期（7月27日—7月31日）
- **地点**：云南寻甸（线下）+ 上海（线上支持）

## "数字魔法师"系列课程

| 课次 | 课题 | 核心概念 | 形式 |
|------|------|----------|------|
| 第1讲 | 0和1的世界 | 二进制、卡片计数 | 游戏 + 身体互动 |
| 第2讲 | 秘密纸条 | 凯撒密码、加密解密 | 手工密码轮盘 |
| 第3讲 | 把大象塞进冰箱 | 游程编码、数据压缩 | 物理演示 + 比赛 |
| 第4讲 | 信息大冒险 | 分包传输、丢包重传 | 角色扮演游戏 |
| 第5讲 | 画里的数字 | 像素、RGB、图像编码 | 方格纸创作 + 交换解码 |

- 每讲 50 分钟，面向 3-6 年级混龄
- 全部零经费道具（卡片、纸条、方格纸、密码轮盘）
- 5 讲形成完整主线：信息编码启蒙
